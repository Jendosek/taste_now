# 🍕 TasteNow - Food Delivery App

Сучасний веб-додаток для доставки їжі, розроблений з використанням React та Firebase.

![TasteNow Banner](public/assets/img/home/images/big_burger.png) 
*(Тут варто вставити посилання на реальний скріншот головної сторінки, коли завантажите його на GitHub)*

## 🛠 Технологічний стек

* **Frontend:**, React Router v6
* **State Management:** Redux Toolkit
* **Styling:** CSS Modules, Responsive Design (Mobile-First approach)
* **Backend / Auth:** Firebase (Authentication, Firestore)
* **UI Components:** Swiper (слайдери), React Icons

## ✨ Ключові можливості

* **Автентифікація:** Повноцінна система входу та реєстрації через Firebase (Email/Password). Перевірка унікальності нікнеймів.
* **Каталог:** Перегляд товарів з фільтрацією за категоріями (Піца, Бургери, Салати...).
* **Інтерактивний кошик:** * Додавання товарів з вибором топінгів (кастомізація).
    * Автоматичний підрахунок суми.
    * Збереження кошика в `localStorage` (дані не зникають при оновленні).
* **Адаптивність:** Повна підтримка мобільних пристроїв та десктопів.
* **Слайдери:** Інтерактивні каруселі для популярних категорій та відгуків.

## 🚀 Як запустити проєкт

1.  **Клонуйте репозиторій:**
    ```bash
    git clone [https://github.com/ВАШ_НІКНЕЙМ/tastenow.git](https://github.com/ВАШ_НІКНЕЙМ/tastenow.git)
    ```

2.  **Встановіть залежності:**
    ```bash
    npm install
    ```

3.  **Налаштуйте Firebase:**
    * Створіть файл `src/firebase.js`.
    * Додайте туди ваш конфіг з консолі Firebase.

4.  **Запустіть локальний сервер:**
    ```bash
    npm start
    ```
